# FastAPI Task Manager (учебный проект)

Простой REST API для управления задачами, написанный на FastAPI.  
Проект создан для изучения основ веб-разработки, контейнеризации (Docker) и развертывания приложений в облаке.

---

## 📝 О проекте

Приложение реализует базовые CRUD-операции (создание, чтение, обновление, удаление) для задач.  
Оно подходит для знакомства с:

- FastAPI и автоматической документацией Swagger UI;
- работой с JSON и Pydantic-схемами;
- Docker-контейнеризацией;
- деплоем на бесплатные облачные платформы.

## 🛠 Локальная разработка

### Вариант 1: Запуск через Python (без Docker)

1. **Клонируйте репозиторий** (или используйте свой форк):
   ```bash
   git clone https://github.com/ваш-username/fastapi-task-manager.git
   cd fastapi-task-manager
   ```

2. **Создайте и активируйте виртуальное окружение**:
   ```bash
   python -m venv venv
   source venv/bin/activate      # для Linux/macOS
   # или venv\Scripts\activate   # для Windows
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите сервер разработки**:
   ```bash
   uvicorn main:app --reload
   ```

5. **Откройте в браузере** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) – вы увидите Swagger UI, где можно тестировать API.

---

### Вариант 2: Запуск через Docker

1. Убедитесь, что Docker установлен на вашем компьютере.
2. Соберите образ:
   ```bash
   docker build -t fastapi-task-manager .
   ```
3. Запустите контейнер:
   ```bash
   docker run -p 8000:8000 fastapi-task-manager
   ```
4. Приложение будет доступно по адресу [http://localhost:8000](http://localhost:8000).

## 📚 API Endpoints

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/tasks` | Получить список всех задач |
| POST | `/tasks` | Создать новую задачу |
| GET | `/tasks/{task_id}` | Получить задачу по ID |
| PUT | `/tasks/{task_id}` | Обновить задачу по ID |
| DELETE | `/tasks/{task_id}` | Удалить задачу по ID |
| GET | `/health` | Проверка работоспособности |

## ☁️ Деплой на бесплатные облачные платформы

### Основной вариант: Render (рекомендуется)

[Render](https://render.com) позволяет бесплатно развернуть веб-приложение из Docker-образа или напрямую из GitHub-репозитория.

**Шаги:**

1. Зарегистрируйтесь на [Render.com](https://render.com) (можно через GitHub).
2. Нажмите **New + → Web Service**.
3. Подключите свой GitHub-аккаунт и выберите репозиторий с проектом.
4. Укажите настройки:
   - **Environment**: `Docker`
   - **Region**: выберите ближайший к вам.
   - **Branch**: `main` (или та ветка, которую хотите деплоить).
5. Нажмите **Create Web Service**.
6. Render автоматически соберёт Docker-образ и запустит приложение.
7. После успешного деплоя вы получите ссылку вида `https://ваш-сервис.onrender.com`.

**Важно:** На бесплатном тарифе сервис «засыпает» при отсутствии запросов, но просыпается при первом обращении (задержка ~15–30 секунд). Для учебных целей этого вполне достаточно.

---

### Альтернатива: PythonAnywhere (с ограничениями)

[PythonAnywhere](https://www.pythonanywhere.com) также имеет бесплатный тариф, но он **не поддерживает FastAPI напрямую** (только WSGI-приложения, например, Flask или Django). Однако вы можете использовать его для демонстрации статической документации или простых API через Flask-адаптер. Для учебного проекта мы рекомендуем **Render**, так как он поддерживает FastAPI «из коробки» через Docker.
